# 要件定義書(Rev.3・確定版)

**プロジェクト**: Affiliate_Roll — 収益化ツールサイト「手取りチェッカー」
**日付**: 2026-07-11 / Rev.1(Nexus 2.0)→Rev.2(収益化転換)→**Rev.3(ターゲット確定・本書)**

## 1. 目的

初期費用0円・ランニングコスト0円で、検索・SNS・AI経由の流入をアフィリエイト収益に変えるツールサイトを構築・運用する。

## 2. 戦略決定(確定済み)

| ID | 決定 | 理由 |
|---|---|---|
| S-1 | 記事型ではなく**ツール型**(計算機・診断)で参入 | AI量産記事・AI要約に代替されない「使う」ページで戦う |
| S-2 | 収益はアフィリエイト優先、AdSenseは独自ドメイン取得後の二軸目 | AdSenseは実質独自ドメイン必須のため0円制約と矛盾 |
| S-3 | ホスティングはCloudflare Pages(静的サイト・無料枠) | サーバー費0円・高速・壊れない |
| S-4 | ニッチは**手取り・社会保険料シミュレーター系**(案A) | 通年需要・毎年の改正で再燃・ツール横展開可・計算根拠が公的で検証可能 |
| S-5 | フレームワーク不使用(素のHTML/CSS/JS・ビルド工程なし) | npm依存の陳腐化を排除し長期運用コストをゼロに |

## 3. ターゲット定義(確定)

**「お金の不安が具体的な数字になった瞬間の人」**
— 転職・扶養・ボーナス・増税などの人生イベントで「自分の場合いくら?」が発生した人。

この層の特性(設計に直結):
1. **正確さへの渇望が強い** — AIの概算では不安。出典明記・公表値どおりの計算が信頼の源泉
2. **プライバシー感度が高い** — 年収をAIチャットに入力したくない。「端末内計算・送信なし」が殺し文句
3. **感情が動いている瞬間である** — アフィリエイト成果が出る唯一のタイミング

包含される具体ペルソナ: 内定通知の額面を見た転職検討者(20-30代)/扶養の壁が怖いパート主婦(40-50代)/ボーナス明細を見た会社員/新社会人。
※「AIを使わない・使えない層」はこの定義に自然に含まれる(狙い方は感情ベースが精度が高い、というディベート結論を反映)。

## 6. KPIと撤退条件

- 公開3か月: 検索流入 500PV/月・初成果1件
- 月1,000PV: 独自ドメイン+AdSense申請(初投資解禁)
- **撤退条件**: 6か月で月500PV未満なら、サイト骨格を流用して案B(引越し費用系)へピボット
- SEOの立ち上がりは3〜6か月かかる。初月収益ゼロは仕様であり失敗ではない
