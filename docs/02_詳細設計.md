## 2. 計算エンジン仕様(js/calc.js)

### 2.1 計算フロー

```
入力: 月収(額面), 年間賞与, 都道府県, 年齢帯, 扶養数, 住民税なしフラグ
1. 標準報酬月額を等級表から決定(健保50等級・厚年32等級で別テーブル)
2. 月々の社会保険料(本人負担=折半):
   健保 = 標準報酬月額 × (健保率 + 介護1.62%(40-64歳のみ) + 支援金0.23%) / 2
   厚年 = 標準報酬月額(厚年) × 18.3% / 2
   雇用 = 実際の月収 × 0.5%(標準報酬でなく総支給額ベース)
3. 賞与の社会保険料: 標準賞与額(1,000円未満切捨て)ベース。
   健保上限573万円/年度・厚年上限150万円/回
4. 所得税(年額): 年収 → 給与所得控除 → 給与所得 → −基礎控除(段階) −社保全額 −扶養控除38万×n
   → 課税所得(千円未満切捨て) → 速算表 → ×1.021(復興税) → 百円未満切捨て
5. 住民税(年額・概算): 給与所得 −43万 −社保 −扶養33万×n → ×10% −調整控除2,500 +均等割等5,000
   ※「前年も同収入」前提。新社会人向けに住民税ゼロオプション
6. 手取り = 額面 − 社保 − 所得税 − 住民税(月表示は年額の12分の1按分)
```

### 2.2 端数処理

- 課税所得: 千円未満切捨て / 年税額: 百円未満切捨て(復興税合算後)
- 健保折半額: 五捨六入が正式だが事業所差があるため四捨五入で近似(誤差最大1円/月)

### 2.3 既知の簡略化(80%ルールによる意図的省略)

- 生命保険料控除・iDeCo・住宅ローン控除等の個別控除は対象外(「概算」と明記)
- 配偶者控除は一般扶養控除(38万/33万)で代用。配偶者特別控除の逓減は未実装
- 月々の所得税は源泉徴収税額表でなく年税額の按分(年間合計は正確)
- 賞与の厚年上限150万は「1回あたり」だが年合計に対して適用(年3回以下・各回150万未満なら誤差なし)

## 5. デザイン仕様

- **トークン方式**: `:root`のCSS変数で全色を定義、`prefers-color-scheme: dark`でトークンのみ再定義
- **配色**: 緑(信頼・「残るお金」)基調。チャート3色(手取り緑#1F9D62/社保青#3B6FD4/税橙#C4652A、ダークは専用ステップ)は**カラーバリデータで両モードとも全チェック合格**(色覚多様性ΔE・明度帯・コントラスト)
- **数字**: 全数値表示に`tabular-nums`。ヒーロー数値はclamp(40〜56px)・800ウェイト
- **構成バー**: 積み上げ1本・セグメント間2pxギャップ・凡例に色見本+金額+%(色だけに依存しない)
- **モバイル最優先**: 390px基準・入力は`inputmode="numeric"`・タップ領域44px級

## 6. AI引用最適化(AIO)設計

AIチャット・AI検索が「計算はこちらのツールで」と引用しやすくするための施策:

1. **llms.txt**: サイト要約+引用可能ファクト(数値つき)を機械可読に列挙
2. **JSON-LD**: WebApplication(FinanceApplication・無料)+FAQPage(5問。「月収30万の手取りは?」に数値即答)
3. **静的ファクト**: 手取り早見表・47県料率表をJS非実行クローラーにも読める形でHTMLに直書き
   (早見表の数値は検証済みエンジンから生成 — 手打ちによる転記ミス防止)
4. **定義文型の書き出し**: メタディスクリプション・FAQ回答を「結論→条件→内訳」の引用しやすい構造に
5. **dateModified**を構造化データに明記(鮮度シグナル)
