# デプロイ手順書(Cloudflare Pages・所要15分)

## 前提
- GitHubリポジトリ: `hokorobi88room/Affiliate_Roll`(サイト本体は `site/` ディレクトリ)
- 費用: 0円(Cloudflare Pages無料枠・クレカ登録不要)

## 1. Cloudflare Pages 初回セットアップ

1. https://dash.cloudflare.com でアカウント作成(無料)
2. 左メニュー **Workers & Pages** → **Create** → **Pages** → **Connect to Git**
3. GitHubを認証し `Affiliate_Roll` リポジトリを選択
4. ビルド設定:
   - **Production branch**: `claude/iphone-app-development-pswowl`(またはmainにマージ後mainを指定)
   - **Framework preset**: None
   - **Build command**: (空欄)
   - **Build output directory**: `site`
5. **Save and Deploy** → 1〜2分で `https://<プロジェクト名>.pages.dev` が発行される

> プロジェクト名がそのままサブドメインになるので `tedori-checker` を推奨。
> 別名にした場合は以下の「URL書き換え」を実施。

## 2. URL書き換え(発行URLが tedori-checker.pages.dev 以外の場合)

`site/` 内の次の箇所を実URLに置換してコミット:
- `index.html`: canonical・og:url・JSON-LD内のurl(2箇所)
- `robots.txt`: Sitemap行
- `sitemap.xml`: loc 3箇所
- `llms.txt`: ページURL 3箇所

```bash
grep -rl "tedori-checker.pages.dev" site/ | xargs sed -i '' 's|tedori-checker.pages.dev|実際のドメイン|g'
```

## 3. 公開後すぐやること(初日)

1. **動作確認**: スマホ実機でツールを触る(月収入力→結果→シェアボタン)
2. **Search Console**: https://search.google.com/search-console → URLプレフィックスで登録
   → 所有権確認は「HTMLタグ」をindex.htmlの`<head>`に貼る → sitemap.xml送信
3. **Cloudflare Web Analytics**: Pagesの設定画面からワンクリック有効化(無料・Cookieレス)
4. **Bing Webmaster Tools**: Search Consoleからインポート(AI検索(Copilot)流入源として重要)

## 4. 更新フロー(日常)

```bash
git pull
# site/ 内を編集
node site/test/test.js   # 料率・計算をいじった時は必須
git add -A && git commit -m "..." && git push
# → push するだけで Cloudflare Pages が自動再デプロイ(1〜2分)
```

## 5. アフィリエイト開始時

1. A8.net に登録(サイトURL = pages.devのURL)
2. 提携承認後、広告リンクを取得
3. `site/data/affiliates.js` に1件追加(ファイル内のコメントに記入例あり)→ push
4. 結果画面直下に枠が自動表示される(「広告を含みます」表記も自動)

## 6. 独自ドメイン移行(月1,000PV到達時)

1. Cloudflare Registrarでドメイン取得(.comで年約1,500円)
2. Pages → Custom domains で接続(SSL自動)
3. 上記「URL書き換え」を新ドメインで再実施
4. Search Consoleに新プロパティ追加(pages.devからの移転はCloudflareのBulk Redirectで301)
5. AdSense申請
