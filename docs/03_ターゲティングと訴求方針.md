# ターゲティングと訴求方針

**日付**: 2026-07-11(ディベート結論の確定版)

## 1. ターゲット定義

### 中心命題
**「お金の不安が具体的な数字になった瞬間の人」を狙う。**
属性(年齢・職業)ではなく「瞬間」でターゲティングする。感情が動いている瞬間だけが、ツール利用とアフィリエイト成果の両方が発生するタイミングだから。

### 「瞬間」の具体例とペルソナ

| 瞬間 | ペルソナ | 検索語の例 | 相性の良い案件 |
|---|---|---|---|
| 内定通知の額面を見た | 転職検討中の20-30代 | 「月収28万 手取り」「年収450万 手取り」 | 転職エージェント |
| ボーナス明細を見た | 会社員全般 | 「ボーナス 手取り 計算」 | 証券口座・ふるさと納税 |
| 扶養の壁が怖い | パート主婦40-50代 | 「106万の壁 損する」 | 格安SIM・保険見直し |
| 4月の初任給前 | 新社会人 | 「初任給 手取り いくら」 | クレカ・銀行口座 |
| 住民税決定通知が届いた(6月) | 全給与所得者 | 「住民税 高い なぜ」 | 固定費見直し全般 |

### ターゲットの3特性(ディベートで確定した設計原則)

1. **正確さへの渇望** — AIの概算では不安。裏取りした公表値+出典明記が信頼の源泉。
   「AIのハルシネーションが不安だから計算ツールで裏取りする」という**AI時代の新需要**も取り込む。
2. **プライバシー感度** — 年収をチャットに打ちたくない(ユーザー説の採用部分)。
   → 技術構成(端末内計算)がそのまま訴求になる。バッジ「入力データ送信なし」をファーストビューに配置済み。
3. **感情が動いている** — だから結果画面の直後が唯一の訴求ポイント。アフィ枠は結果直下の1枠のみ。

### 採用しなかった説とその理由(記録)
「計算ツール利用者=AI非利用者」説は部分採用。AI利用者も金額計算ではツールで**裏取り**する(LLMは複合計算を間違える)ため、AI回避層だけに絞ると市場を狭める。属性でなく感情の瞬間で狙えば、AI回避層は自然に包含される。

## 2. 訴求コピー方針(営業全書の適用ルール)

持ち込み資料『人間学・全書(ネットビジネス特化版)』のフレームをサイト・SNS両方に適用する。

### 結果画面(サイト内)
- **現在進行形の損**の型: 「あなたの社会保険料は年◯◯円 — ここは減らせません。減らせるのは固定費です」
- 数値化→累積化の順(「月345円→年4,140円」)
- アフィ枠は**価値提示(計算結果)の後**にのみ置く(希少性・オファーを冒頭に置かない原則)
- 「広告を含みます」を明記(2-4: 営利目的を正直に言った方が聞いてもらえる)

### X運用(1日1投稿・5分)
- 冒頭はフック4型のみ: ①現在進行形の損 ②クイズ・数字の問い ③ビフォーアフター(間を伏せる) ④ギャップ
- 属性の名指し: 「皆さん」禁止 → 「額面30万で手取りを即答できないあなた」
- 情報満足の罠回避: 計算方法は教えない。「自分の数字」への好奇心だけ残してツールへ(CTA=負担極小の「30秒」)
- CTAは言い切り+低ハードル: 「30秒だけこれ見てください」
- 3回角度替えして反応ゼロの切り口は捨てる(三度押しの撤退線)

### 投稿テンプレ例(初週用)
1. 損型: 「2026年4月から、給与明細に新しい天引きが増えたの気づいてました?『子ども・子育て支援金』月収30万で月345円。自分の額はここで30秒→」
2. クイズ型: 「額面30万円の手取り、即答できますか?答えは約24.0万円(東京・独身)。6万円どこに消えたか30秒で内訳が見えます→」
3. ギャップ型: 「今年、手取りが『増える』改正があったの知ってますか?基礎控除104万円。年収500万以下は所得税が下がってます。自分の額は→」

## 3. 集客チャネル(運用方針書に詳細)

SEO(遅効・柱)+X(即効)+季節イベント便乗(6月住民税・7/12月賞与・11-12月ふるさと納税・1-3月新生活)+AI引用(llms.txt等)の4チャネル。検索単独依存にしない。
