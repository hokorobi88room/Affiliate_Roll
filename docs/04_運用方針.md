# 運用方針書

**日付**: 2026-07-11

## 1. 運用の総コスト設計

**1日5分(X投稿)+週15分(数字確認)。毎日ブログ投稿はしない(ツール型を選んだ理由そのもの)。**

| 頻度 | 作業 | 時間 |
|---|---|---|
| 毎日 | X投稿1本(用意済みテンプレから貼るだけ)・リプ確認 | 5分 |
| 週1 | Search Console/Cloudflare Analyticsの数字確認・伸びた検索語のメモ | 15分 |
| 月1 | 伸びた切り口へのテンプレ補充・FAQ追記 | 30分 |
| 年2回 | **2月**: 協会けんぽ新料率反映(rates2026.jsのみ)/**12月**: 税制改正大綱チェック | 各1時間 |

## 2. 集客4チャネル

### ① SEO(柱・遅効)
- 主戦キーワード: 「手取り 計算」系ビッグ+「月収◯万 手取り」「◯◯県 健康保険料率」ロングテール
- 対策済み: タイトル/メタの年号明記・FAQ構造化データ・早見表/料率表の静的HTML・出典明記
- デプロイ後にやること: Search Console登録→sitemap.xml送信(手順書05参照)
- 期待値: 3〜6か月で立ち上がり。初月ゼロは仕様

### ② X運用(即効)
- 1日1本、フック4型ローテーション(訴求方針書03のテンプレ)
- 全投稿のCTAはツールURL(登録不要・30秒・送信なし=負担極小オファー)
- 結果シェア機能がツール自体を拡散装置にする(シェア文言は成果数値入りで設計済み)
- 撤退線: 同じ切り口3回で反応ゼロなら切り口を変える(単純再放送はしない)

### ③ 季節イベント便乗(年間カレンダー)
| 時期 | イベント | 事前仕込み(2週間前) |
|---|---|---|
| 1-3月 | 確定申告・新生活・転職繁忙期 | 「初任給手取り」投稿を集中投下 |
| 4月 | 新年度料率適用・新社会人 | 料率更新の告知投稿(「今月から天引きが変わった」) |
| 6月 | 住民税決定通知 | 「住民税高い」系投稿+住民税解説追記 |
| 7月/12月 | ボーナス | ボーナス手取り投稿(Phase 2でツール化) |
| 11-12月 | 年末調整・ふるさと納税駆け込み | ふるさと納税ツール(Phase 2)を最前面に |

### ④ AI引用(新規性のある差別化)
- 実装済み: llms.txt・FAQPage/WebApplication構造化データ・静的ファクト・dateModified
- 狙い: AIチャット/AI検索が金額計算の裏取り先として当サイトをリンクする流れ
- 計測: Analyticsのリファラー(chatgpt.com / perplexity.ai / claude.ai等)を月次で確認

## 3. アフィリエイト方針

1. **枠は結果画面直下の1枠のみ**(信頼優先。ベタベタ貼らない)
2. 文脈一致の原則: 計算結果(社会保険料の重さ)→固定費見直しの提案、の順序を崩さない
3. 表記: 「※このリンクはアフィリエイト広告を含みます」を枠内に常時表示(実装済み・ステマ規制対応)
4. 提携順序: A8.net(審査緩・サブドメイン可)→ もしもアフィリエイト → 成果が出たら高単価案件へ
5. 実装: `site/data/affiliates.js` に1件追加するだけで表示される(コード変更不要)
6. 案件候補(文脈一致順): 格安SIM/電力・ガス切り替え/保険相談/転職エージェント/ふるさと納税サイト

## 5. 禁止事項(信頼を守る)

- 誇張した節約額・オーバートーク(事実に加えた誇張はその分だけ真実を軽くする)
- 出典のない数値の掲載
- 結果より前(ファーストビュー)への広告設置
- 「あとで直す」つもりの古い料率の放置(正確性がこのサイトの唯一の堀)
